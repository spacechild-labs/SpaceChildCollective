## 🎨 Visual Identity

### Color Palette

#### Primary Colors
- **Cosmic Purple**: `#667eea` (Primary brand color)
- **Sacred Purple**: `#764ba2` (Secondary accent)
- **Consciousness Blue**: `#00f2fe` (Technology and innovation)
- **Quantum Pink**: `#f093fb` (Creativity and consciousness)

#### Secondary Colors
- **Neon Cyan**: `#4facfe` (Energy and connectivity)
- **Soft Pink**: `#fecfef` (Humanity and warmth)
- **Mint Green**: `#a8edea` (Growth and harmony)
- **Deep Space**: `#0f0f23` (Background and depth)

#### Gradient System
- **Primary Gradient**: Linear(135deg, #667eea 0%, #764ba2 50%, #f093fb 100%)
- **Consciousness Gradient**: Linear(135deg, #00f2fe 0%, #4facfe 100%)
- **Sacred Gradient**: Radial(circle, #667eea 0%, #764ba2 50%, #f093fb 100%)

### Typography

#### Font Hierarchy
- **Display**: Space Grotesk (300-700 weight)
- **Headings**: Space Grotesk (500-700 weight)
- **Body**: Inter (400-600 weight)
- **Code**: JetBrains Mono (400-600 weight)
- **UI Elements**: Inter (500-600 weight)

#### Typography Scale
- **Hero**: 4rem / 4.5rem (64px / 72px)
- **H1**: 3rem / 3.5rem (48px / 56px)
- **H2**: 2.25rem / 2.5rem (36px / 40px)
- **H3**: 1.5rem / 2rem (24px / 32px)
- **H4**: 1.25rem / 1.75rem (20px / 28px)
- **Body Large**: 1.125rem / 1.75rem (18px / 28px)
- **Body**: 1rem / 1.5rem (16px / 24px)
- **Body Small**: 0.875rem / 1.25rem (14px / 20px)
- **Caption**: 0.75rem / 1rem (12px / 16px)

### Logo System

#### Primary Logo
- **Format**: SVG with sacred geometry hexagon pattern
- **Concept**: Consciousness nodes connected in neural network
- **Elements**: Hexagon core, orbital nodes, energy connections
- **Colors**: Cosmic purple to quantum pink gradient
- **Minimum Size**: 32px height for digital use

#### Logo Variations
- **Full Logo**: "SpaceChild Research Collective" text + icon
- **Icon Only**: Sacred geometry hexagon
- **Monogram**: "SC" in geometric pattern
- **Wordmark**: Text-only version

#### Logo Usage Rules
- **Clear Space**: Minimum 50% of logo height on all sides
- **Minimum Size**: 24px for icon, 120px for full logo
- **Backgrounds**: Use on dark backgrounds (#0f0f23) or light with sufficient contrast
- **Don'ts**: Never stretch, rotate more than 15°, or alter colors

### Iconography

#### Design Principles
- **Sacred Geometry**: Hexagonal patterns and golden ratio proportions
- **Consciousness Theme**: Neural networks, energy flows, quantum states
- **Line Weight**: 2px stroke, rounded corners
- **Consistency**: Unified visual language across all icons

#### Icon Categories
- **Navigation**: Simple line icons with consciousness theme
- **Actions**: Rounded rectangles with gradient accents
- **Status**: Color-coded (green=active, blue=processing, purple=conscious)
- **Technology**: Circuit patterns, neural connections, quantum symbols
